# SSearch
Chrome插件，用于信息收集

## 😣用途

每次谷歌语法搜索时还得自己写，我想省事一点，弄了一个插件，先加了几个常用的语法，点击后会跳转到对应搜索页面，也可以直接在搜索框微调

后续也会加些其他语法

